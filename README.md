# Starting Application - NextJS TypeScript
Edu2Skill AI – AI Teaching Assistant 🎓

Edu2Skill AI is an AI-powered educational platform that helps students learn programming, understand code, debug errors, and improve their coding skills.

Features

- AI Teaching Assistant
- Code Explanation
- Code Debugging
- Programming Help
- MCQ Generation
- Practice Questions

Objective

To make programming education easier, smarter, and more interactive through artificial intelligence.

Target Audience

Computer Science students and beginner programmers.

Learn Smart. Code Better!
